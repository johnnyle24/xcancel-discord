# XCancel Discord Bot

Simple discord bot using python wrapper for discord library

## QuickStart

### Setup

You must have pip3, python3, and the requisite libraries installed.

```bash
pip3 install discord
python3 xcancel.py
```

### Troubleshooting

If you see certificate errors, you will need to run

```bash
pip3 install certifi
```

If you receive 401 errors, the token is invalid
